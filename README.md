# Homestead Harvest

A modern, fast, and responsive React frontend for a live geo-seed, bulb, and plant marketplace. Built with Vite, React, TypeScript, Tailwind CSS, and shadcn/ui.

## Features
- **Dynamic Marketplace**: View products, providers, and planting experts.
- **Mock Authentication**: Quickly simulate user flows without needing a backend.
- **Modern UI**: Polished, animated components using Tailwind and Radix UI.

## Getting Started

1. **Install Dependencies**
   ```bash
   npm install
   ```

2. **Run Development Server**
   ```bash
   npm run dev
   ```
   *The app will be available at `http://localhost:8080` (or another port based on Vite config).*

## Technologies Used
- **Vite** - Next Generation Frontend Tooling
- **React 18** - The library for web and native user interfaces
- **TypeScript** - Strongly typed programming language that builds on JavaScript
- **shadcn/ui** - Beautifully designed, accessible components
- **Tailwind CSS** - A utility-first CSS framework

## Architecture
This project is currently isolated on the frontend to allow for rapid UI/UX iteration. It is prepped for connection to any backend service (like Node.js servers, Firebase, or Supabase).
